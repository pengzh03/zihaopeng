# 基于分组逃逸的2.5D芯粒布线算法

## 项目说明

* 项目最终报告：`2.5D芯粒布线_报告.pdf`

* 分工情况：
  * 于鉴轩：基于层分配的总线布线算法、逃逸位置构建算法、逃逸布线算法、进行部分实验、完成最终报告中实验部分
  * 陈佳华：线网分类算法、基于模式的区域布线算法、多线程实现、进行部分实验、完成最终报告中引言部分

## 运行条件和方法

请确保在 C++ 11 以及 Linux 平台下运行

进入项目目录，使用如下命令编译：

```
make
```

运行时需要指定输入和输出文件的路径，具体方法如下所示：

```
./build/router [path of grid_layout.json] [path of netlist.json] [path of routing_result.json]
```
